# Customer Churn Analysis

## Project Overview

Customer churn is a major challenge for businesses because losing customers directly impacts revenue and growth. This project analyzes customer data to identify patterns associated with customer attrition and provides insights that can help improve customer retention.

## Objective

The objective of this project is to:

* Analyze customer churn behavior
* Identify factors influencing customer attrition
* Explore customer demographics and account information
* Generate business insights for customer retention

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Analysis Performed

* Data Cleaning
* Dataset Overview
* Customer Churn Analysis
* Gender Analysis
* Geography Analysis
* Age Distribution Analysis
* Age vs Churn Analysis
* Balance vs Churn Analysis
* Active Member Analysis
* Credit Card Analysis
* Correlation Heatmap
* Churn Rate Analysis

## Key Findings

* Older customers show higher churn rates.
* Customer churn varies across geographic regions.
* Active members are less likely to leave the bank.
* Customer balance and age influence churn behavior.
* Customer retention strategies should focus on high-risk customer groups.

## Conclusion

The analysis identified important customer characteristics associated with churn. Understanding these patterns can help businesses improve customer retention, reduce revenue loss, and support data-driven decision-making.
